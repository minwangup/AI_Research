# Academic CV

Single-file LaTeX CV (`cv.tex`) built on the CurVe class.

## Build

```bash
pdflatex cv.tex
pdflatex cv.tex   # second pass for the section tables
```

Overleaf: upload this folder, set `cv.tex` as the main document, compiler pdfLaTeX.

Replace `figures/photo.jpg` (currently a placeholder) with your own photo.
